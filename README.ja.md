# mekuriawase-lesserpanda

愛らしいレッサーパンダをテーマにした、シンプルなブラウザベースの絵合わせゲーム（めくりあわせ）です。カードをめくって同じペアを見つけ、記憶力を試してみましょう！ゲームボードはオープンデータを活用して動的に生成されます。

## デモ

**ゲームはこちらで遊べます: https://code4fukui.github.io/mekuriawase-lesserpanda/**

## 特徴

- **カードの動的生成:** ゲームカードは、リモートにあるレッサーパンダのデータのCSVファイルからリアルタイムに生成されます。
- **記憶力チャレンジ:** オーソドックスな16枚（8ペア）の絵合わせゲームです。
- **クリアタイムの記録:** すべてのペアを見つけると、クリアタイムが記録されアラートで表示されます。
- **リプレイ機能:** 「Retry」ボタンを押すと、カードがシャッフルされてもう一度遊ぶことができます。
- **インストール不要:** セットアップは一切不要で、すべてウェブブラウザ上で動作します。

## 遊び方

1. [デモリンク](https://code4fukui.github.io/mekuriawase-lesserpanda/)を開きます。
2. 任意の2枚のカードをクリックしてめくります。
3. カードのレッサーパンダが一致した場合、カードは表向きのままになります。
4. 一致しなかった場合、少し待つと裏向きに戻ります。
5. できるだけ早くすべてのペアを見つけることが目標です。

## ローカルでの実行

ご自身のPCでこのプロジェクトを実行するには、リポジトリをクローンし、`index.html`をウェブブラウザで開いてください。

```bash
git clone https://github.com/code4fukui/mekuriawase-lesserpanda.git
cd mekuriawase-lesserpanda
# index.htmlをブラウザで開く
```

レッサーパンダのデータや必要なJavaScriptライブラリ（`shuffle.js`、`CSV.js`）を取得するため、インターネット接続が必要です。

## データソース

このゲームは、レッサーパンダに関するオープンデータのコレクションである[lesserpanda-opendata](https://github.com/code4fukui/lesserpanda-opendata)プロジェクトの写真と情報を使用しています。
